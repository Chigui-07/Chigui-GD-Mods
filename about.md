# Demon Tracker

**Demon Tracker** es un mod de Geometry Dash creado con Geode para construir una clasificacion personal de demons basada en la experiencia real del jugador.

## Objetivo de la v0.1

La primera version busca establecer una base estable del mod:

- Cargar correctamente con Geode.
- Anadir un acceso desde el menu principal.
- Preparar el sistema de datos para demons completados.
- Crear la primera interfaz de listas.
- Preparar el cuestionario personal de dificultad.

## Clasificacion personal

Al completar un demon, el jugador respondera un cuestionario sobre dificultad general, consistencia, precision, control, aprendizaje y presion. El resultado determinara su posicion dentro de las listas personales.

Una vez confirmada, la clasificacion relativa del demon sera permanente.
